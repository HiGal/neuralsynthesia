# NeuralSynthesia Frontend

Modern Vue 3 frontend for the NeuralSynthesia AI Storybook Generator.

## Features

- 🎨 Modern, beautiful UI with gradient effects
- 🚀 Built with Vue 3 Composition API
- ⚡ Vite for fast development and building
- 📱 Fully responsive design
- 🎭 Smooth animations and transitions
- 🎤 Voice recording with WebRTC
- 📖 Beautiful storybook viewer

## Tech Stack

- **Vue 3** - Modern reactive framework
- **Vite** - Next-generation frontend tooling
- **Pinia** - State management
- **Axios** - HTTP client
- **Canvas API** - Animated particle background

## Development

### Prerequisites

- Node.js 18+ and npm

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run serve
```

The app will be available at `http://localhost:8080`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Configuration

Create a `.env` file for development:

```env
VITE_API_BASE_URL=http://localhost:5000
```
